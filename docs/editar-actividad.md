# DF-09 · Editar una actividad

«Acciones de {actividad}» abre el menú de la tarjeta en el listado del cuidador. «Editar actividad» abre el formulario compartido con los datos guardados. Los pasos se precargan como personalizados. Un cambio de nombre permite aplicar una sugerencia mediante la confirmación existente.

Guardar conserva la identidad de la actividad y usa la revisión leída. Los avisos para una ejecución iniciada o completada se actualizan con la respuesta del servidor. Cerrar la confirmación conserva abierto el formulario, y «Ver actividades» vuelve al listado, que se actualiza al recuperar el foco.

Ante un conflicto o un resultado incierto, se conserva el borrador y se puede consultar la versión guardada. Si se elige cargar otra versión, se confirma antes de reemplazar el borrador.
